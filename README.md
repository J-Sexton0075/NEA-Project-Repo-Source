# NEA-Project-Repo-Private
Source code for my A-Level Computer Science NEA project. 

A smart calendar app to help students plan, track and monitor their study. 

Unfortunately no git history since I worked in a separate repository I wish to keep completely private. I think now if I was asked to do my NEA again I would choose perhaps a more advanced or complex topic and if I was to do this specific project again there would be many changes I'd make with my approach and organisation.

The main thing I think I got from this project (other than an A-Level grade) is the experience working on something big, even if I now know areas where I'd make changes in my approach I am happy that this has given me the experience of managing a particularly complex program. Since this project I feel as if I've begun to make further improvements on skills such as writing clean, documented code and although I think I made a pretty good effort to keep this well structured, I definitely think that documentation and structure is something that still can be approved on on top of this. 

No generative AI was used creating this project. 
This was submitted as an assessed piece of work and all sources used were referenced in my project report and well documented and detailed there.
